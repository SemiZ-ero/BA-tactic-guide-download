# 블루 아카이브 택틱 가이드

블루 아카이브 PC판의 전투 화면을 읽어서, 정해 둔 택틱대로 EX를 쓰고 있는지 알려 주는 프로그램이에요.
총력전, 대결전, 제약해제결전처럼 EX 순서가 정해진 보스 전투를 하려고 만들었어요.

화면을 읽기만 하고, 게임에 클릭이나 키 입력을 보내지는 않아요.

## 할 수 있는 것

전투 중
- 남은 시간, 코스트, 보스 HP, 손패를 화면에서 읽어요. 손패는 3장과 5장(제약해제결전)을 알아서 구분해요.
- 게임 화면 위에 다음에 쓸 EX 카드를 표시해요. 쓸 차례가 되면 "지금!"으로 바뀌어요.
- 게임 창 옆에 정보 창이 붙어서 택틱 진행표와 판정 기록을 보여 줘요.
- 계획보다 늦게 쓰거나 순서를 건너뛰면 알려 줘요. 일시정지도 알아봐요.
- 전투가 끝나면 결과 화면을 읽고 택틱을 몇 단계까지 진행했는지 보여 줘요.
- F7(한 단계 되돌리기), F8(다음 단계), F9(처음부터)는 게임 중에도 써요. 인식이 놓쳤을 때 손으로 맞출 수 있어요.

택틱 만들기
- 표에 한 줄에 EX 하나씩 적어요. 엑셀이나 구글 시트에서 복사해 붙여 넣어도 돼요.
- 커뮤니티 공략 글의 택틱 부분을 붙여 넣으면 프로그램 형식으로 바꿔 줘요.
- 녹화 영상이나 영상 링크에서 초안을 만들 수 있어요. 누가 몇 코스트에 EX를 썼는지를 채워 줘요.
- 만들어 둔 택틱을 공략 영상과 나란히 놓고 비교할 수도 있어요.
- 택틱 목록에서 검색, 복제, 이름 바꾸기, 삭제를 해요.

그 밖에
- 블루 아카이브를 끄면 프로그램도 같이 꺼지게 할 수 있어요.
- 새 버전이 나오면 켤 때 알려 주고, 누르면 업데이트해요.
- 정보 창의 도구 메뉴에서 프로그램을 지울 수 있어요.

## 필요한 것
- Windows PC와 PC판 블루 아카이브. 게임은 창 모드나 전체 창 모드(테두리 없음)로 켜 주세요. 독점 전체 화면에서는 오버레이가 보이지 않아요.
- 초대 코드. 이 프로그램을 알려 준 사람에게 받아야 해요.
- Python 3.12. 없으면 설치할 때 안내가 나와요.
- 처음 설치할 때는 인터넷 연결이 필요해요.

## 설치
1. [BA택틱가이드.exe](https://github.com/SemiZ-ero/BA-tactic-guide-download/raw/main/BA택틱가이드.exe)를 받아요.
2. 받은 파일을 실행해요. Windows가 "PC 보호" 창을 띄우면 [추가 정보]를 누르고 [실행]을 눌러요. 서명이 없는 개인 프로그램이라 처음 한 번 이렇게 나와요.
3. 설치 위치를 정해요. 기본은 `%LOCALAPPDATA%\Programs\BA-tactic-guide`이고, [찾아보기]로 다른 드라이브나 폴더도 고를 수 있어요. 시작 메뉴에도 넣을지, 설치가 끝나면 방금 받은 설치 파일을 지울지 고르고 [설치]를 눌러요. 설치 파일은 한 번 쓰고 나면 필요 없어서 지우는 쪽이 기본으로 켜져 있어요.
4. 초대 코드를 붙여 넣어요.
5. 필요한 프로그램을 받느라 몇 분 걸려요. 끝나면 바로 켜져요.

설치가 끝나면 바탕 화면에 '블루 아카이브 택틱 가이드' 바로 가기가 생겨요. 다음부터는 그걸로 켜요.

Windows 보안이나 백신을 끌 필요는 없어요.

## 처음 쓸 때
- 처음 켜면 택틱이 비어 있고, 정보 창에 쓰는 법이 나와요. [불러오기]에서 택틱을 고르거나 [만들기]에서 직접 써요. 목록에 [예시]로 표시된 택틱으로 먼저 써 볼 수 있어요.
- 화면 영역은 PC 16:9 화면에 맞춰져 있어요. 인식이 이상하면 [도구 ▼ → 화면 영역 보정]으로 맞춰 주세요.
- 학생 아이콘은 처음 켤 때 같이 받아요. 실패해도 프로그램은 켜지고, 나중에 [도구 ▼ → 학생 아이콘 받기]로 다시 받을 수 있어요.

## 알아 둘 점
- 코스트를 줄이거나 되살리는 효과가 있으면, 코스트로 짐작한 판정은 틀릴 수 있어요. 카드 그림이 등록돼 있으면 더 정확해요.
- 게임 업데이트로 화면 구성이 바뀌면 영역 보정을 다시 해야 할 수 있어요.
- 컴퓨터가 바쁘면 판정이 늦어질 수 있어요. 녹화 프로그램을 같이 돌릴 때 특히 그래요.
- 일시정지 창이나 다른 창이 손패를 가리는 동안 쓴 EX는 알 수 없어요.

## 지우기
정보 창에서 [도구 ▼ → 프로그램 제거]를 누르면 돼요. 직접 만든 택틱은 바탕 화면에 백업해 둘 수 있어요.
